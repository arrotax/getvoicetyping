Settings

  1. 1Press Start dictation and allow the microphone when asked.
  2. 2Speak naturally. Each phrase appears in the note as you finish it.
  3. 3Say the punctuation. "Comma", "full stop", "new line" become marks — the words for each language are under Spoken punctuation.
  4. 4Say "scratch that" to take the last phrase back out.
  5. 5Dictation stops by itself after 30 seconds of silence, or on Esc.

Notes

Every note is saved as you type. The star keeps a note at the top; folders group them — make one with "+ New" above the list, then pick it in the box above the note. Notes stay in this browser only, so take a backup from Settings now and then.

Where the audio goes

Recognition is done by Chrome, so the audio goes to Google's speech service the way it does for any site that uses it. This page has no server of its own: notes stay in this browser and nothing is uploaded.

Spoken punctuation

Say the word while dictating and the mark appears. Leave a field empty to switch that one off.

Backup

Notes live in this browser only — there is no account yet. Clearing the browser's site data, or opening the page in another browser, starts from nothing. A backup is one file with every note and your punctuation words; restoring merges it into what is here and never deletes anything.

Privacy

Notes stay in this browser's storage and are never uploaded. Speech recognition is done by Chrome, which sends the audio to Google's speech service — this page has no server of its own and stores no audio.
