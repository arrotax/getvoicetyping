How it works

  1. 1Press Start dictation and allow the microphone when asked.
  2. 2Speak naturally. Each phrase appears in the note as you finish it.
  3. 3Say the punctuation. "Comma", "full stop", "new line" become marks — the words for each language are set below.

Recognition is done by Chrome, so the audio goes to Google's speech service the way it does for any site that uses it. This page has no server of its own: notes stay in this browser and nothing is uploaded.
